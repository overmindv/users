# Users

Users - identity service платформы Overmindv. Он владеет пользователями, паролями, профилями, ролями и выпуском JWT.

## Функционал

- регистрация обычных пользователей;
- вход по email и паролю;
- получение и обновление профиля пользователя;
- soft delete пользователя;
- список пользователей для администраторов;
- назначение и снятие роли `admin`;
- bootstrap первого суперпользователя при старте.
- безопасный публичный профиль и авторизованный поиск по username, имени и фамилии;
- установка и удаление `avatar_file_id` с transactional outbox для Media.

## Бизнес-логика

Обычный пользователь может читать доступный контент через frontend, но не управляет каталогом и другими пользователями. Администратор имеет все права обычного пользователя и может выполнять admin-only операции через api-gateway. Суперпользователь создаётся первым bootstrap-аккаунтом, всегда считается администратором и нужен для назначения первых админов.

Users является единственным источником истины по ролям пользователей. api-gateway читает роли из JWT и прокидывает запросы управления пользователями обратно в Users.

Связью пользователя с аватаром владеет Users. Перед изменением сервис проверяет готовый публичный avatar-файл через Media, затем атомарно сохраняет `avatar_file_id` и outbox-событие. Процесс `users-worker` идемпотентно переключает binding в Media; поэтому временная недоступность Media не приводит к потере изменения.

## Запуск

Локально сервис запускается в составе общего окружения из `infra`:

```bash
cd ../infra
cp .env.example .env
make up
```

Для разработки самого сервиса:

```bash
make generate
make test
make integration
make build
```

API и worker используют разные процессы одного image. Для локального запуска worker требуется `MEDIA_URL`, `MEDIA_USERS_TOKEN`, `USERS_WORKER_HTTP_ADDR` и применённая миграция `202608170001_user_avatars.sql`.

PostgreSQL component-тесты требуют отдельный DSN и запускаются командой:

```bash
make ctest COMPONENT_TEST_DSN='postgres://postgres:postgres@localhost:5432/users?sslmode=disable'
```
